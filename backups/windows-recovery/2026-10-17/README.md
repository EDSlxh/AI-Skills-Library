# ChatGPT / Codex 本地恢复索引

这是一个小型、脱敏的恢复索引。它记录本机相关目录的用途、扫描时大小、已知来源，以及在 D 盘重新建立 Skill 工作目录的方法。

**公开包不包含个人文件内容，也不是完整电脑备份。仅靠它不能恢复个人项目、聊天记录、照片、账号状态或本地修改。**

- `inventory.csv` / `inventory.json`：目录清单、大小、来源及迁移状态。用户名已替换成 `%USERPROFILE%`；没有个人项目名称或逐文件路径。
- `sources.json`：本地 Skill 库版本、geo-sleuth 上游版本、两个模型的下载地址、固定 revision、大小和 SHA-256。
- `RESTORE.md`：重装和恢复顺序，以及仍必须保留的本地数据。
- `Restore-To-D.ps1`：默认仅预览；加 `-Apply` 后在一个全新的 D 盘目录克隆固定版本的公开 Skill 库，创建进程级缓存环境脚本。不删除原件，不改系统配置，不自动安装依赖或下载模型。
- `Verify-Package.ps1` / `SHA256.json`：核对包内文件完整性。校验通过不代表全部功能已经恢复。
- `recovery-index.zip` / `recovery-index.zip.sha256`：便于下载的同内容压缩包及校验值。

本机另存的 `LOCAL-ONLY-selected-sources.zip` 与 `local-*` 清单不上传 GitHub。它们包含筛选的源码/小文档副本及详细目录索引，仍排除了照片、二进制文档、聊天历史、登录凭据、模型和依赖缓存等；筛选规则和遗漏在本地索引内。D 盘不是异地备份，同一电脑或磁盘损坏仍可能影响它。

扫描采用真实文件 ID 去重硬链接，大小表示文件数据字节，并非“占用空间”。扫描时应用仍运行，结果不是原子快照；跳过目录联接/符号链接，并报告访问失败数。安装包目录、已由 Windows 管理到 D 盘的应用数据未计入所列 C 盘根目录总量。

当前迁移尚未切换：D 盘原有文件是较早的暂存副本，本次没有重新证明与 C 盘完全一致。**不要根据本索引删除 C 盘项目或 `.codex`。**

除能由 Git 配置、上游说明、部署记录及固定模型哈希确认的来源外，来源只记录到管理工具或用途；不能证明每一个文件最初从哪个网址下载。部署时版本不代表现在重新解析依赖会得到相同版本。
