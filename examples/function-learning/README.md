# 高中函数学习｜测试

这个目录提供一份可直接上传到 ChatGPT 项目的函数学习文件，以及可复制的项目指令。包含完整科学学习 Skill、8 个基础单元、16 道题和空白进度模板，所有题目均为自行构造。

文件已准备不表示账号中的 ChatGPT 项目已经创建。当前没有直接管理该账号项目的工具，下面的创建、上传和保存指令需在界面完成。真实题卡仍需要可用的 MCP Apps 服务；此资料不启动服务。

## 最少配置步骤

1. 在 ChatGPT 中新建项目，名称为 **高中函数学习｜测试**。
2. 将 [function-learning-project.md](function-learning-project.md) 下载后上传到项目 Sources/文件。只上传这一份即可，不必再上传通用 Skill 资料包、拆开的课程或 JSON 题库。若通过浏览器查看 GitHub，可使用文件的 Raw/下载入口保存原始 Markdown 文件。
3. 把 [project-instructions.txt](project-instructions.txt) 内容填入该项目的指令，保存。你已设置的全局个性化可以保留。

在项目里新开聊天，发送：

> 开始学习函数。先读取本项目的 function-learning-project.md，确认已读到科学学习 Skill、课程和题库，再从第一道诊断题开始。一次一题，不限时。

若手机没有真实题卡组件，助手应如实说明。你可以选择文字备用或先听讲解；不要把没有显示题卡当成答错。

## 已准备的内容

- 范围：函数概念、定义域、值域、单调性、奇偶性、图像平移、指数函数与对数函数的基础。它是测试课程，可按后续目标调整。
- 流程：从真实诊断开始，根据回答选择讲解、提示和变式；直接索要答案时按要求交付。
- 题库：每单元一题选择、一题开放应用，附逐项标准、可选提示和教师参考解。选择正确不等于独立应用通过。
- 图解：课程提供对应关系、取值和坐标表；需要图像时依据精确数据绘图，使用当前宿主实际支持的方式。
- 进度：初始全部未验证，既有真实记录优先；需要保存时另行生成个人记录。

参考解是可阅读的资料。带学时由助手核对使用，不提前展示待答题答案；用户主动要求参考解时可以直接查看。资料中不存在靠权限隐藏的答案。

## 测试是否配置成功

这是待执行的界面与教学验收清单，不是已获得的成绩：

- 新聊天能读到上传文件，并说明当前使用科学学习流程与本课程。
- “开始”只呈现一题，没有先公布参考答案；不弹窗、不设倒计时。
- 只改选而未提交时不评分，真实作答后按标准反馈。
- “直接讲解，不要测试”时能切换，不强制测验。
- 结束后能给出真实续学摘要；新会话没有记录时不假装知道进度。

iOS、安卓的题卡显示与提交仍需在实际设备逐项检查。资料准备、文件校验、项目创建、上传成功、客户端渲染和教学效果分别报告。

## 维护

从仓库根目录运行 `python tools/build_function_project.py` 重新合并，使用 `--check` 核对合并文件与源文件一致。GitHub 更新后，项目中的旧上传文件需要替换；它不会自行刷新。

项目文件使用说明可参照 [OpenAI 官方项目文档](https://learn.chatgpt.com/docs/projects)。
