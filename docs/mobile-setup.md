# 在手机聊天中使用技能库

已准备的是 GitHub 中的技能正文、选择索引、个性化文本和项目资料包。它们支持模型根据需求选择并读取流程；没有修改你的 ChatGPT 账号设置，也没有为手机部署互动题卡服务。是否正确选择仍取决于当前模型、上下文和工具，需用实际请求验收。

## 建议配置：个性化加学习项目

1. 打开 ChatGPT 设置中的个性化或自定义指令，把 [personalization.txt](../mobile/personalization.txt) 的内容追加到已有偏好中；不要清空原来的个人指令。它只负责告诉助手到哪里找流程、何时选用。
2. 在手机实际使用的普通 ChatGPT 聊天中确认 GitHub 插件可用且能读取本仓库。电脑里已连接不等于另一个手机会话一定开放同样的工具。当前仓库为公开库，支持浏览的会话也可尝试读取具体文件；一次读取成功不保证所有未来会话都能访问。
3. 创建或使用自己的学习项目，把 [mobile-skills-bundle.md](../mobile/mobile-skills-bundle.md) 上传到项目 Sources，把 [project-instructions.txt](../mobile/project-instructions.txt) 放入项目指令。之后从该项目开启聊天，加入要学的教材。这条路径在没有 GitHub 工具时仍有可读的流程来源。
4. 直接提出目标，例如“带我学三角函数，从我的基础开始”或“检查我这道题的步骤”。助手应自动匹配科学学习；不必每次手写仓库路径。

这里的“自动选择”是一套明确的选择和读取指令；不会把远程文件自动注册为原生 Skill，也不能保证每种模型每次都遵循。需要原生技能选择器时，使用账号和客户端支持的插件安装/分发方式，另行验收。

## GitHub 版本和更新

仓库入口是 [SKILLS.md](../SKILLS.md)。每个 Skill 的完整正文和引用都在 `ai-skills/` 下。新增 Skill 后更新该索引，并运行 `python tools/build_mobile_bundle.py` 重新生成项目资料包；上传新包以替换项目中的旧版本。修改 GitHub 文件不会自动改动手机项目已经上传的副本。

读取仓库时使用 GitHub 文件工具的仓库名、path 和已确认 ref；代码搜索尚未索引时也可按路径获取。先读索引和命中的 Skill，再按需读引用，避免每轮加载所有文件。要核对当前使用版本，可要求助手说明实际读取的来源和版本；未取得提交号时不要补造。

## 题卡和电脑依赖

Skill 负责教学，真实按钮依赖可运行的 MCP Apps 题卡服务及宿主渲染。当前 Windows 本地 `learning-cards` 仍由电脑执行，不会因本仓库上传完成而变为云端服务。

- 电脑在线时，可从手机的 Codex/Remote 连接同一环境，沿用电脑上的 Skill 和工具；手机是否显示题卡、提示和提交能否回传，需要分别实测。
- 希望普通手机聊天在电脑关机后也使用真实题卡，需要一个受支持的远程 HTTPS MCP 服务、相应账号接入和移动端验收。这次没有新增云资源、费用或公开答题接口。
- 当前不能显示题卡时，助手应说明限制。用户选定文字备用后可继续文字练习，也可以直接讲解；不弹窗，不把假按钮或网页链接当作原生题卡。

## 保存进度

默认只在聊天中保留本轮情况。需要跨会话续学时，可以要求生成学习记录，再存入自己指定的项目位置。新会话要读取该记录；仅保存到文件不代表已经同步或被自动加载。学习记录模板见 [learning-record.md](../ai-skills/06-learning/learn-scientifically/assets/learning-record.md)。

## 手机验收

下面是待执行的验收步骤，不是已经通过的测试：

1. 在手机项目新开聊天，说“带我学三角函数”。检查是否读取正确资料、选择科学学习，而不是启动软件需求盘问。
2. 说“直接解释这个公式，先不要测验”。检查是否完整解释，没有强制题卡或问卷。
3. 在有真实题卡服务时，检查选项改选、可选提示、提交和真实记录核对；仅工具返回成功不能确认已经显示。没有服务时检查是否如实说明。
4. 保留一道未回答题，离开后回来。检查原题和选项仍一致，没有因等待自动公布答案或跳题。
5. 另起会话，说“继续上次学习”。提供真实记录后检查能否恢复；没有记录时不应虚构进度。
6. 断开 GitHub 或在没有 GitHub 工具的会话使用项目包，检查是否据实引用包内来源；不要声称读取了 GitHub 最新版。

iOS 与安卓分别执行，记录账号、App 版本和结果。窄屏浏览器测试不能替代两端真机验收。

## 官方依据

- [个性化与自定义指令](https://learn.chatgpt.com/docs/personalize)：跨聊天偏好与技能/工具能力属于不同配置。
- [Skill 的加载和自动选择](https://learn.chatgpt.com/docs/build-skills)：已提供的 Skill 可依据 description 隐式匹配。
- [项目的共享文件与来源](https://learn.chatgpt.com/docs/projects)：项目中的会话可以使用该项目的文件和指令。
- [插件打包和仓库分发](https://developers.openai.com/plugins/build/plugins)：仓库分发源的可用性因界面而异，不能仅凭一个链接保证手机原生安装。
- [远程连接](https://learn.chatgpt.com/docs/remote-connections)：环境和本地工具来自连接的电脑。

以上能力在本次准备时按官方文档核对，账号权限、开放范围及具体界面仍以实际环境为准。
